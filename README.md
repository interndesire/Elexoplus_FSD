# Elexoplus - Employee Management System Landing Page

A modern, responsive, and clean landing page designed for the Elexoplus Employee Management System (EMS). This project was built as part of the Full Stack Development (FSD) Internship submission.

##  Tech Stack Used
* **HTML5:** For semantic web structure and SEO-friendly layout.
* **CSS3:** For modern typography (Inter Font), smooth hover transitions, and a clean color scheme.
* **Vanilla JavaScript (ES6):** For dynamic interactions, mobile menu toggling, and interactive registration modal popups.

##  Key Features
*  **100% Fully Responsive:** Looks perfect on desktops, tablets, and smartphones.
*  **Interactive Mock Dashboard:** A live-coded CSS preview metrics component showcasing active employees and real-time attendance.
*  **Dynamic Sign-Up Modal:** Clean popup form for corporate admin registration without page reloads.
*  **Smooth Scrolling:** Enhanced navigation linking seamlessly across feature matrices.
